# Content Briefs

One brief per planned article, named `<slug>.md`, written by the nightly routine
before drafting. A brief contains:

- **Primary keyword** + 3–5 secondary keywords (from DataForSEO / GSC).
- **Search intent** (informational / commercial / local).
- **Angle** — the specific take that differentiates this from generic content
  (usually a Ghana-specific lens).
- **H2 outline** — each H2 with the one-sentence citable claim it opens with.
- **Internal links** to include (related articles + a product/pillar page).
- **FAQ questions** to answer (real "people also ask" queries).

The two foundation articles (`hba1c-explained`, `preventive-health-screening-ghana`)
were authored directly as the reference implementation; subsequent articles get a
brief here first.
