# Off-Site Authority Queue

Ranking #1 on competitive terms needs authority signals (citations + backlinks),
not just on-page work. This folder is the **queue** the weekly off-site routine
tops up and a human acts on. Most off-site steps need an account or a human
sign-off (you cannot, and should not, auto-spam directories), so the routine
prepares the work; a person executes and records the outcome.

## Files

- `directory-targets.md` — NAP-consistent business directory + citation submissions.
- `digital-pr-angles.md` — story angles for earned media / backlinks.

## NAP (keep identical everywhere — consistency is the ranking signal)

```
Name:     BetterHealth Africa
Address:  Accra, Greater Accra, Ghana
Phone:    +233 26 859 6410
Email:    hello@betterhealth.africa
Website:  https://www.betterhealth.africa
```

Confirm this NAP against the live Organization schema before submitting anywhere;
mismatches hurt more than missing citations.

## Workflow

1. Weekly routine adds/refreshes targets and angles here.
2. A human submits / pitches and fills in the `status` + `submitted` columns.
3. Won backlinks/citations are logged so we don't duplicate effort.
