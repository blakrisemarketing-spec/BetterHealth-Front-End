# 100 Healthy Years Foundation landing page

The foundation landing page lives at the route **`/foundation`** inside this existing
BetterHealth front-end (React + Vite + Tailwind). It is intentionally self-contained: it does
not reuse the commercial `Nav`/`Footer`, and it ships its own brand register (visionary,
public-facing copy with no clinical jargon).

## Files

- `src/pages/Foundation.jsx` — the page, composed of all sections in order.
- `src/components/foundation/FoundationNav.jsx` — slim sticky nav, anchor links, mobile menu.
- `src/components/foundation/FoundationFooter.jsx` — foundation footer (contact + socials mirror the main BetterHealth site).
- `src/components/foundation/forms.jsx` — Volunteer (name/email/phone/profession/message), Partner, Newsletter forms + Support modal body.
- `src/components/foundation/Gallery.jsx` — two auto-scrolling marquee rows; each photo is clickable and opens an accessible lightbox (Esc / arrow keys / click-out). Hover or press pauses a row; reduced-motion users get scrollable rows instead.
- `src/components/foundation/primitives.jsx` — `Reveal`, `CountUp`, `ImagePlaceholder`, `Modal`.

## Logo

The foundation wordmark is the BetterHealth Africa logo recoloured to the foundation amber
(`src/assets/foundation/logo-foundation.png`, generated by hue-shifting the sage in
`src/assets/logo.png` to amber while keeping the charcoal "Africa"). It is shown in the nav and
footer with a small "Foundation" descriptor.

## Contact details (single source)

Email, phone, WhatsApp, and the social links live at the top of `FoundationFooter.jsx` and match
the main BetterHealth Africa site (`hello@betterhealth.africa`, `+233 26 859 6410`, same
Facebook / Instagram / X / TikTok / WhatsApp URLs). Update them there.

## How to run

Standard project scripts (no extra setup):

```bash
npm install
npm run dev      # then open http://localhost:5173/foundation
npm run build
```

## Where to swap the accent colour

The amber accent is **provisional** and isolated so it can change in one place. Edit the
`accent*` tokens in **`tailwind.config.js`** (`accent`, `accent-light`, `accent-soft`,
`accent-dark`, `accent-glow`, `accent-bg`). Changing `accent` (`#D4A24E`) re-themes every
foundation button, highlight, and the stats/"100 healthy years" emphasis. The gold gradient
orb tint lives in `src/components/ui/GradientOrb.jsx`.

Text on the amber background uses `text-text-primary` (dark charcoal `#2B3A3A`), not white,
to pass WCAG AA (~5.6:1). Keep that pairing if you change the amber.

## Typography

Headings use **Quicksand** (`font-heading`); body uses **Inter** (`font-inter`). Both are loaded
in `index.html` via a single Google Fonts call with `display=swap`.

## Images

Real screening photos (June 2026 PCC event) live in `src/assets/foundation/`, optimised to
web-sized WebP (52-110 KB each) with EXIF rotation baked in. They are imported in `Foundation.jsx`:

| Slot | File | Notes |
|---|---|---|
| Hero | `hero-screening.webp` (4:3) | eager + `fetchPriority="high"` (above the fold) |
| What We Do | `what-we-do.webp` (3:2) | `loading="lazy"` |
| Proof band | `proof-screening.webp` (4:5) | `loading="lazy"` |
| Get Involved | `get-involved.webp` (3:2) | `loading="lazy"` |
| Gallery | `src/assets/foundation/gallery/g01..g08.webp` | marquee rows + lightbox, all `loading="lazy"` (~387 KB total) |

To swap a photo: drop a new optimised WebP into `src/assets/foundation/` (or `.../gallery/`) and
update the import. Source originals were re-encoded with PIL (resize longest side,
`ImageOps.exif_transpose`, WebP q78-80). Keep every image dignified (no staged suffering) and add
descriptive `alt` text. Gallery captions/alts are the `IMAGES` array in `Gallery.jsx`.

`ImagePlaceholder` (in `primitives.jsx`) is still available for any future slot that does not yet
have a real photo; it renders a warm sage/amber block labelled with the expected shot.

## Forms → email

All five foundation forms POST through `submitPartnerSignup` (`src/lib/partner-signup.js`) to the
same backend the For Doctors / For Labs forms use (`VITE_PARTNER_API_URL`), which emails
**ops@betterhealth.africa** via Resend. Each carries a `partnerType`:

- `foundation_volunteer` — Volunteer signup
- `foundation_partner` — Partner / funder enquiry
- `foundation_newsletter` — Newsletter signup
- `foundation_screening_request` — a community (church/school/etc.) requesting a free screening
- `foundation_screening_partner` — a group with an upcoming screening wanting our platform

On failure the form shows an error with a `mailto:hello@betterhealth.africa` fallback.

## SEO / social sharing

This is an SPA served by Hostinger/LiteSpeed, so crawlers/social scrapers that don't run JS only
see `index.html`'s (main-site) meta. To fix that for `/foundation`, `vite.config.js` has a
`prerender-route-seo` plugin that writes `dist/foundation/index.html` at build time with the
foundation-specific `<title>`, description, Open Graph/Twitter tags, canonical, and NGO JSON-LD
baked in. LiteSpeed serves that file as the directory index for `/foundation/` (the `.htaccess`
SPA rewrite skips it because the directory exists). The share image is `public/foundation-og.jpg`
(1200×630). Client-side, `Foundation.jsx`'s Helmet sets the same tags. To add another route's SEO,
append to the `PRERENDER` array in `vite.config.js`.

## Accessibility & performance notes

- Scroll reveals use `IntersectionObserver` + CSS transitions (no animation library on this
  page) and are fully disabled under `prefers-reduced-motion`; `CountUp` renders its final value
  immediately in that case.
- Modals trap focus on open, close on `Esc` and outside-click, and lock body scroll.
- Verified: no horizontal overflow at 360px, AA contrast on amber pairings, keyboard-operable
  nav/forms/modals, visible focus rings.
