This is the shared, repository-tracked content system for Codex, Claude, and any other agent that can read Markdown. It separates strategy, copy, health-safety checks, visual production, and publishing so that a finished post has a traceable path from idea to asset.

## Shared Rules

- Treat health content as general education. Do not make unsupported or diagnostic claims.
- Use the Council as distinct lenses; do not blend them into a pretend all-knowing agent.
- Design the post around one job and one audience action.
- For visual work, choose the visual mode before designing and render-inspect every final image.
- Record verified sources and unresolved proof gaps in the content kit.

The OpenAI Workspace Agent IDs in the Council registry are useful only inside OpenAI. The named lenses, review template, content workflow, and visual instructions are deliberately platform-neutral.
