# BetterHealth Social Content Pipeline

Produce reusable posting kits, not isolated captions or image prompts.

## Read First

1. Read `../../content-pipeline/PLAYBOOK.md`.
2. Read `../../copywriting-council/README.md` when the request needs copy strategy, hooks, positioning, or a Council review.
3. Read `../bh-social-visual-system/SKILL.md` when the request creates or changes a social visual.
4. Read `../bh-social-visual-system/references/copy-rules.md` before approving health copy.

## Workflow

1. Build the brief using `../../content-pipeline/templates/content-brief.md`.
2. Select only the Council lenses relevant to the brief. Use the Chair to synthesise, naming material disagreement rather than averaging it away.
3. Make one core message, one post job, and one CTA explicit.
4. Draft the carousel/frame sequence, caption, platform adaptations, Stories, visual production brief, sources, and QA record using `../../content-pipeline/templates/content-kit.md`.
5. Treat health material as general education: distinguish symptoms, risks, tests, and diagnosis; do not create unsupported certainty.
6. Select the visual mode before art direction. For rendering and image QA, follow `bh-social-visual-system` rather than duplicating its instructions.
7. Save durable work under `../../social-content/` as `day-NNN-posting-kit.md`.

## Council Routing

For a social post, start with three to six lenses, not the entire Council.

- Use `Tested Advertising Methods` for first-slide hooks and stop power.
- Use `Breakthrough Advertising` for awareness, desire, and belief gaps.
- Use `Ogilvy on Advertising` for evidence and trust.
- Use `The Copywriter's Handbook` for structure and CTA clarity.
- Use `Made to Stick` for a concrete, memorable device.
- Use `Scientific Advertising` for proof gaps and learning metrics.
- Add `Positioning` for category or brand claims, and `Influence` for ethical persuasion or trust signals.

Use `../../content-pipeline/templates/council-review.md` to capture the review.

## Done Means

- The kit has a clear brief, Council synthesis, copy, source links, guardrails, CTA, and platform adaptations.
- The visual brief identifies the correct mode and the one visual idea before design begins.
- Health claims use careful language and retain unresolved proof gaps rather than inventing evidence.
- Rendered visual assets have passed the visual-system QA check.
