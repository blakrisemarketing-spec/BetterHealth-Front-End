# Portable Agent Use

This skill is written for Codex, but the workflow is deliberately portable. An agent without Workspace Agent support should use the book-lens names in `../../copywriting-council/README.md` as independent review passes and then write a Chair synthesis.

The Workspace Agent IDs in `registry.json` are OpenAI-specific identifiers. Do not treat them as required inputs or evidence of access to any source book.

Use this repository entry point when another agent needs onboarding: `CLAUDE.md` at the repository root, then `.agents/content-pipeline/PLAYBOOK.md`.
