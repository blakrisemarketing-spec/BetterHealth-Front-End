# BetterHealth Social Visual Modes

## Shared Brand Rules

- Logo: use BetterHealth Africa logo, usually top-left.
- Type: Quicksand only, weights 300-700.
- Core colours: warm cream `#F5F3EE`, sage `#6B8E7F`, deep text `#2B3A3A`.
- Educational medical accent: restrained red `#9F3033`; do not use red by default when sage can carry the emphasis.
- Cards: use only for content modules, CTAs, or repeated items; do not put cards inside cards.
- Safe zones: keep important copy comfortably inside the frame.
- Footer disclaimer: use for health education posts.

## Visual Clarity Check

Before creating or rendering a slide, answer these questions:

1. What is the one idea this asset must explain?
2. What is the simplest visual metaphor for that idea?
3. Can someone understand the visual in three seconds without reading every word?
4. Are all chart, graph, timeline, and data elements internally consistent?
5. Is anything decorative enough to confuse the message?

If the answer to question 3 is no, simplify the visual. If the answer to question 5 is yes, remove the confusing element.

## Sprint Lessons To Apply

- The visual must explain the idea before the copy does.
- Do not default to blood imagery for every blood-test topic. Ask what best communicates the message. For example, HbA1c vs fasting blood sugar is better shown as single reading vs longer pattern, not as blood cells.
- Use dramatic black-gradient hero treatments when they improve scroll-stopping power, but keep the metaphor obvious.
- Use sage as the default emphasis colour; reserve red for moments where it adds meaning.
- Middle carousel slides should be calmer than hero slides: readable, literal, and easy to save/share.
- Remove any object a viewer might ask, "what is that supposed to be?"
- Simpler visuals often look more premium than crowded explainers.
- Render inspection is mandatory because HTML/CSS can look logical while the final PNG has overlaps.

## Strict Brand Image

Use for single-image posts and brand-led messages.

Layout patterns:
- Logo top-left, badge/top-right if campaign-coded.
- Large type-led headline.
- One supporting paragraph or CTA block.
- Plain cream background or subtle brand texture.
- Sage CTA button or accent block.

Avoid:
- cinematic blood scenes;
- busy medical backgrounds;
- dramatic black/red unless it is a campaign hero;
- heavy shadows or too many cards.

## Explainer / Educational Carousel

Use for carousel middle slides and medical education.

Layout patterns:
- Full-frame realistic medical background.
- Cream haze/gradient behind text for readability.
- Left-side copy block, right-side concept visual.
- Small callout label only if it identifies a visual element.
- One idea per slide.

Visual standard:
- Red blood cells should look like realistic biconcave cells.
- White blood cells should look textured and organic.
- Platelets should look like small realistic fragments/clusters.
- Organs/test domains should look like subtle translucent clinical forms, not flat icons.
- Charts must obey chart logic: dots sit exactly on the line, labels do not collide, and every plotted element has a reason.
- Timelines must use clear labels such as Month 1, Month 2, Month 3; avoid abstract date objects or decorative stacks if they are not immediately legible.
- Comparison slides should make the contrast visible first, then support it with copy.

Avoid:
- flat vector cells;
- icons pasted onto a plain canvas;
- in-image AI text;
- overexplaining with too many labels.
- floating data points that are not on the plotted line;
- decorative medical objects that do not explain the specific concept;
- chart labels, badges, or cards covering plotted data.

## Real-Life Human Story

Use for human-centered patient or booking scenes.

Composition:
- Overhead or over-the-shoulder for phone screens.
- Center the human action and relevant object.
- Ghana-market realism: ordinary rooms, modest furniture, lived-in surfaces, natural clutter.
- Keep phone/screen readable only when it matters.

Avoid:
- illustrated humans;
- luxury interiors that feel like a millionaire home abroad;
- weird phone angles where the screen is visible unrealistically;
- sterile stock-photo perfection.

## Scroll-Stopping Hero

Use for carousel first slides and campaign openers.

Allowed:
- black/red dramatic backgrounds;
- high-contrast macro medical scenes;
- oversized typography;
- stronger visual metaphor than normal brand posts.
- black gradients and high contrast when they make the idea clearer and more dramatic.

Required:
- logo or brand signal;
- Quicksand;
- safe-zone readability;
- few words;
- clear reason to stop scrolling.

Decision rule:
- Start with the message, not the medical category. Ask: "What is the best way to visually communicate this to the user?"
- If the answer is a comparison, show the comparison. If the answer is time, show time. If the answer is a human behavior, show a real human behavior.
