# BetterHealth Agent Guide

For BetterHealth social or editorial work, begin with the agent kit in [`.agents/README.md`](.agents/README.md).

- Use the Copywriting Council as separate book lenses and preserve useful disagreement.
- Use the social content pipeline to produce a brief, a review record, a posting kit, and a production brief.
- Use the BetterHealth Social Visual System for social images; it owns brand modes, safe zones, image prompts, rendering, and visual QA.
- Treat health content as general education. Do not invent clinical claims or make a test sound diagnostic by itself.

Keep final, reusable content kits in `.agents/social-content/`.
